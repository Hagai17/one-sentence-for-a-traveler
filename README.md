A tiny Python program that writes one sentence to `/output/entry.txt`: a single line of at most 200 characters explaining the modern internet to a time traveler who has just stepped out of the year 1800, built only from things that person already knows — a post office, a library, a desk, a letter, and a cup of tea going cold. The sentence was picked by drafting ten candidates and duelling them pairwise on the bounty judge's own criteria — the traveler grasps what the internet is and does, every anchor predates his time, nothing claimed would mislead a literal reader, no word is filler and no features are listed, and one image stays in the memory — then defending the winner against four revision-round challengers, one of which beat it by putting the pen in the traveler's own hand. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
